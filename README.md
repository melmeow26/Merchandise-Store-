# Merchandise-Store-
Make sure you've installed XAMPP and Visual Studio Code
Make sure your XAMPP have this two compenents: MySQL, phpMyAdmin
Make sure your environment variable had C:/xampp/php
start the Apache and MySQL in XAMPP
click config (apache)>php.ini, search gd and remove it's semicolon
Import merchandise.sql that I given inside the folder
Make sure your Visual Studio Code installed this extension: PHP Intelphense
Open the Merchandise store folder on Visual studio code,then click View>terminal, insert php -S localhost:8000
click both CTRL and the link given in terminal at the same time, and you are ready to go!
